# Picksy

Picksy(픽시)는 AI 기반 판단·선택·평가 기능을 HTTP API로 제공하는 Rust 기반 Self-hosted 서비스입니다.

특정 애플리케이션에 종속되지 않고, 개발 도구와 게임 서버 등 다양한 클라이언트가 공통으로 사용할 수 있는 AI 판단 API를 지향합니다.

## 주요 활용 방향

- 개발 도구의 후보 선택과 결과 평가
- 게임 서버의 NPC 행동 및 전술 선택
- 동일한 입력에 대한 모델별 판단 품질과 응답 시간 비교

## 설계 방향

- **Rust · Axum**으로 API 인증, 요청 검증, 호출 제한을 처리합니다.
- **d1-2B Q4_K_M**을 추론 모델로 채택하며, API 서버와 추론 서버를 분리합니다.
- **Caddy**로 HTTPS와 요청 분산을 구성합니다.
- **SQLite**로 API Key 관리 정보와 사용량을 저장합니다.
- **Docker Compose**로 로컬 개발과 서버 실행 환경을 구성합니다.
- **GitHub Actions**로 검사·이미지 빌드·배포를 자동화하는 것을 목표로 합니다.

API는 허가된 클라이언트만 사용할 수 있도록 설계하며, 모델 변경이 외부 API에 미치는 영향을 최소화하고자 합니다.

## 현재 상태

단계 0~3을 완료하고 d1 Q4를 채택했습니다. 공식 llama.cpp 단일 서버의 로컬 HTTP 추론을 확인했지만, 과거 풀 실험이 d1 복제 검증을 뜻하지는 않습니다. 단계 4 진행은 승인됐으며 아직 미구현입니다. Rust+d1+Caddy 재통합·OMP 종단·ARM64 운영은 미검증입니다. [현재 설계와 검증 범위](docs/wiki/wiki.md)를 참조하세요.

로컬 개발과 자체 서버 운영을 통해 Rust, AI 추론 서비스, 컨테이너 및 CI/CD를 학습하는 프로젝트입니다.
