# Picksy 핵심 규칙

상세 작업 방법은 [AGENTS.md](AGENTS.md), 현재 설계는 [Wiki](../docs/wiki/wiki.md)를 따른다. 이 파일은 모든 작업의 체크리스트가 아니라 놓치면 위험한 경계만 유지한다.

- 외부 요청은 Gateway 인증을 통과한다. 내부 Caddy 리스너와 Laya를 외부에 노출하거나 인증 우회 경로를 만들지 않는다.
- Gateway와 Laya는 독립 풀이다. 복제본 자동 탐색·준비 상태·분산은 실제로 검증하며, 복제본 증가만으로 성공을 선언하지 않는다.
- 로컬 DB를 운영으로 복사하지 않는다. 운영 배포·DB 변경은 별도 승인 후 백업 → Migration 단일 실행 → 성공 시 배포 순서를 따른다. 이미지 롤백과 DB 복구는 다르다.
- 비밀값과 민감한 요청·결과 본문을 로그·문서·저장소에 남기지 않는다. Laya의 응답·모델·confidence 의미를 임의로 꾸미거나 Jev와 같다고 가정하지 않는다.
- 구현·실행·배포 검증을 구분한다. amd64 결과로 ARM64 동작·성능을 보장하지 않는다. 실패를 숨기기 위해 인증·검사·오류 처리를 무력화하지 않는다.
- 요청된 단계 안에서는 수정과 필요한 검증을 이어서 완료한다. 작은 수정마다 재승인·전체 검사·새 세션을 요구하지 않는다. 운영·삭제 등 별도 승인 대상은 기존 안전 지침을 유지한다.
- 규칙·스킬·문서 수정만으로 새 세션을 요구하지 않는다. 현재 세션에서 변경 파일을 읽어 적용 가능한 지침을 반영한다. 도구 등록·설정 등 실제 재로딩이 필요한 경우에만 이유와 재시작 범위를 설명한다.
